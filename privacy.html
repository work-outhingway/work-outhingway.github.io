広告について

当サイトは、第三者配信の広告サービス「Google AdSense」を利用しています。筋骨格アトラスの画面下(パソコンでは右側のパネルの下)など、「広告」と表示した枠が広告です。

Google などの広告配信事業者は、Cookie を使用して、利用者が当サイトや他のサイトに過去にアクセスした情報に基づいて広告を配信します。Google は広告 Cookie を使用することにより、利用者が当サイトや他のサイトにアクセスした際の情報に基づいて、Google やそのパートナーが適切な広告を表示できるようにしています。

  • パーソナライズ広告は Google の広告設定 で無効にできます。
  • 第三者配信事業者の Cookie は www.aboutads.info で無効にできます。
  • Google によるデータの扱いは Google のポリシーと規約(パートナーのサイトやアプリでのデータ使用) をご覧ください。

当サイトが集める情報

当サイトは会員登録やお問い合わせフォームを持たず、有料プランのお支払い(下記)を除いて、氏名・メールアドレスなどの個人情報を集めていません。3Dモデルの操作はすべて利用者のブラウザの中で行われ、操作内容をサーバーに送ることはありません。

当サイトは GitHub Pages で配信しています。GitHub はアクセスの記録(IP アドレスなど)を保存することがあります。詳しくは GitHub のプライバシーステートメント をご覧ください。

有料アプリのお支払い

有料アプリのお支払いは Stripe, Inc. の決済画面で行います。カード番号などの支払い情報は Stripe が受け取り、当サイトには送られません。当サイトが Stripe から受け取るのは、お名前・メールアドレス・購入した商品・支払いの状況で、領収書の発行とお問い合わせへの対応にだけ使います。Stripe によるデータの扱いは Stripe のプライバシーポリシー をご覧ください。

購入した内容と広告なしの設定は、利用者のブラウザ(localStorage)に保存するだけで、当サイトのサーバーには送りません。
