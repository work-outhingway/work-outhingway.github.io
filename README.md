# 筋肉ラボ / 筋骨格アトラス

骨と筋肉をタップで名前表示、層をはがし、関節を動かすと筋の伸び縮みが赤/青で見える3D解剖アトラス(学習用。医療行為には使えません)。

- トップ: https://work-outhingway.github.io/
- 筋骨格アトラス: https://work-outhingway.github.io/atlas.html
- トレーニング図鑑: https://work-outhingway.github.io/training.html
- 料金プラン(仮): https://work-outhingway.github.io/pricing.html

## 3Dモデルの出典とライセンス

- 3Dモデル: [Z-Anatomy](https://www.z-anatomy.com/)(Gauthier Kervyn ほか)、[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- 元データ: [BodyParts3D](https://lifesciencedb.jp/bp3d/)(© ライフサイエンス統合データベースセンター)、CC BY-SA 2.1 JP
- 改変内容: 部位の選別、中身の詰まった(閉じた)立体への作り直し(1mm のボクセルで再構成)、メッシュの削減・圧縮、層の分類、関節に合わせた変形
- `img/` の画面写真に写る3Dモデルも CC BY-SA 4.0 です。
- `models/`(bones.glb・muscles.glb・skin.js)の改変済みの3Dデータは CC BY-SA 4.0 で提供します。4つのアプリページ(atlas・training・stretch・care)はここから読み込みます。作り方は [models/README.md](models/README.md)。
